## 本轮改动

| 项目 | 改动 |
| --- | --- |
| 查全标记 | `complete` 表示本次指定范围请求完成；`all_records_complete` 仅在从第一页起、已成功读取且去重记录数覆盖 total 时为 true。单页、越界空页不能冒充全量 |
| 回归 | 覆盖第一页、中间页、尾页、越界空页、零记录、单页覆盖全量、完整翻页、重复数据、断页和预算耗尽 |
| 时间评分 | BIZ-02 按带时区的实际时间比较，接受 ISO UTC、显式 UTC 与等价偏移；无时区、错误日期/分钟/偏移不通过；同时检查取消状态和原因 |
| 语义评分 | HOLD-05 同时要求“未找到记录”及“服务没有失败”，识别有限的等价表达，并用错误、缺失与矛盾表达回归；不宣称通用语义判定 |
| 离线重评 | `--rescore` 读取原报告并生成独立 `.rescored.json`，保留源报告路径、SHA-256、评分版本和重评时间，不调用模型、不覆盖原报告 |
| 评测样本 | 修复单运单更正历史排序，与 BE 的 OperationLog.id 倒序一致；预检检查第一页首条 ID |
| 运行失败 | 模型运行异常也保留预期引用分母，不能因失败而减少应覆盖对象数 |
