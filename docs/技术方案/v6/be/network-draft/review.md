# 全国主要城市站点与线路清单（待 review）

日期：2026-10-01。此清单是 JINGPO 演示网络的配置建议，尚未导入系统；不是承运商实际运营线路或已确认的车辆班次。

## 目标与范围

一次准备主要城市站点和常规城市间线路，后续批量同步，免去逐条手动添加。共 **44 个站点、61 组双向连接、122 条单向线路**。覆盖大陆各省会、自治区首府和直辖市，以及部分重要非省会城市；港澳台及其他城市暂不纳入。

每城一个站点，可作为首次入站站、运单目的站或中转站。不划分大型枢纽与末端网点。只创建站点和线路，不创建 V6 完整路径方案，不变更现有运单。

## 后续同步规则

- 使用现有网络 API 创建，保留幂等和操作历史。站点、线路编码和线路起终点均不可修改。
- 同步前读取实际站点与线路。站点编码冲突、同名不同编码、能力不一致时先形成差异清单；不自动覆盖旧配置。
- 线路同时按编码和有向起终点核对。已有同起终点的线路复用原编码，不因草案编码不同重复创建。
- JSON 中的 origin_station_code / destination_station_code 是清单引用，调用创建线路 API 前必须解析为实际 station ID；JSON 不是可直接 POST 的请求体。
- 保留已有 A/B/C 或其他业务配置；创建缺少项目，记录新建、复用、冲突和失败结果。

完整机器可读清单：[major-city-network.json](major-city-network.json)。系统字段依据：[V3 网络规格](../../../v3/be/spec.md)。
