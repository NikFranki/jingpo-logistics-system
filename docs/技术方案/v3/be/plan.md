## 1. 实施顺序

```mermaid
flowchart LR
    R[确认范围与规则] --> M[数据模型与迁移演练]
    M --> N[网络配置接口]
    N --> B[物流操作解除固定网络]
    B --> F[前端动态配置和操作]
```

各步骤独立核验；完成前一项再推进。数据库约束、服务和客户端作为一次切换发布，开发库不用于破坏性测试。

## 2. 首批实现边界

先完成后端模型与迁移演练，再做配置接口；不要直接去掉 A/C 校验而丢失首站、目的站规则。测试使用独立 *_test 数据库，新建 GZ→WH→HZ 网络，保留 A→B→C 回归样本。
