# V8 待办

V7 当前流程可使用运输线路、班次和计划车次完成运输安排。以下缺口留到 V8 处理，不属于当前版本发布阻塞项。

| 待办 | 当前问题 | 完成标准 |
| --- | --- | --- |
| 登录、固定角色与数据权限（BE/FE/Agent 已接入，浏览器整体验收待完成） | 公司不同用户需要独立身份、数据范围及 Agent 回答风格 | 注册/验证/密码找回/Google 登录、唯一 admin 用户管理、单角色固定权限、自己的订单和运单隔离、Agent 只读与个人身份；详见 [V8 PRD](JINGPO-logistics-system-v8.md)、[BE spec](../../技术方案/v8/be/spec.md)、[BE plan](../../技术方案/v8/be/plan.md)、[FE plan](../../技术方案/v8/fe/plan.md)、[Agent plan](../../技术方案/v8/agent/plan.md) |
| 站点服务范围管理 | 后端支持揽收/派送范围，但前端没有配置页面；目前只能通过接口维护 | 可在网络配置中按省、市、区设置站点的揽收或派送范围，并预览订单/运单匹配结果及冲突 |
| 自动创建运单后的排程补偿 | 新订单创建时会尝试自动排程；已有订单手动创建运单不走同一流程。创建时缺少站点、线路或班次时，后续补齐配置不会自动重试 | 新订单和已有订单创建运单共用自动排程流程；暂时无可用班次时可在配置补齐后重试，且操作幂等、失败原因清楚 |
| 线路版本与计划车次同步 | 线路编辑会提升线路版本，但候选车次查询和审核未处处拒绝旧线路版本快照 | 线路调整后未使用的旧版本车次不再可选，按新版本补生成未来车次；已关联/已执行历史保留且不被静默改写 |
