# 鲸破物流领域术语

本文件定义订单、运单与物流节点的业务含义。

## Language

**订单**：记录下单时确认的商品、收发人及地址信息。创建运单后，订单中的地址保留原始下单信息。

**运单**：记录一件货物的履约信息。创建时复制订单地址；运单地址是当前用于揽收和配送的地址，可以与订单地址不同。

**揽收**：从发件人处接收货物。揽收完成不代表货物已经进入首站。

**入站**：货物实际到达并被站点接收。首次入站和后续运输任务到达都属于入站。

**运单阶段**：一张运单当前所处的履约环节。阶段只表达环节；具体站点由最近一次扫描记录表达，正在运输的线路由当前任务表达。

**轨迹事件**：已经发生的一次物流事实。事件按时间追加，同一张运单可以多次发车、入站。

**运输任务**：沿一条线路运送一批运单的一趟运输。已规划的未来任务可以等待货物就绪，任务状态还表达尚未发车、运输中、已经到达或已取消。

**站点**：接收、处理或交接货物的物流节点。首站、中转站、配送站描述站点在履约中的作用，不代表特定名称或编码。

**运输线路**：连接一个起点站和一个终点站的有方向运输关系。一条线路可以承载多趟运输任务。

**运单目的站**：一张运单计划结束站间运输、由其组织最终派送的站点。目的站与当前所在站、某趟运输任务的终点是不同概念。

**运输任务取消**：撤销尚未发车的一趟运输安排，解除关联运单的安排与占用并保留原任务历史。相关下游未执行安排需要重新审核，货物实际位置和履约事实保持原样。

**目的站更正**：修正运单负责最终派送的站点安排，并保留更正原因和前后记录。更正本身不代表货物移动，也不改变收件地址。

**运单运输路径**：一张运单计划依次经过的站点及站间运输段。已实际执行的部分属于运输历史，后续未执行部分属于可调整的运输安排。

**路径方案**：可供多张运单复用的完整站间运输安排，连接首站和目的站。运单采用方案后拥有自己的路径，后续方案变化不应改写其已发生的运输历史。

**路径接续站**：未来运输安排的起点。在站货物从当前站接续，运输中的货物从本段运输的终点接续。

**标准运输时长**：货物沿一条线路从起点发车到终点到达的预计耗时。不同日期出发的运输可采用同一标准时长。

**中转处理时长**：货物到达中转站后，预计完成卸货、分拣、装车等处理所需的时间。处理完成表示具备继续运输的条件。

**运输时间计划（schedule）**：先有运单，再按这张运单的起终点和完整路径生成各站时间预览；经人工确认后形成各段计划出发和到达安排。确认前是可修改的预览，明确调整时保留先前已确认计划。

**最新预计到达时间**：根据现有运输安排、实际进度和已知耗时估算的当前到达时间。它可以随延误变化，不代表已经实际到达。

**自动运输安排**：人工确认完整运输计划后，系统自动生成各段任务或归入兼容的一趟运输。未来任务等待货物实际到站后执行，任务生成本身不表示已经发车或到达。

**未来任务关联**：一张运单与尚待前序运输完成或首站入站的一段任务之间的计划关系。同一运单可以具有多个未来任务关联。

**当前执行占用**：一张运单当前正在等待发车或正在运输的一趟任务所持有的执行资格。同一运单最多具有一个当前执行占用。
