# BE 目录规则

继承根目录 [协作规则](../AGENTS.md)。本目录负责物流事实、业务权限和运输安排。

## 重点目录与入口

| 入口 | 用途 |
| --- | --- |
| `main.py`、`config.py`、`db.py` | 应用、配置与数据库连接 |
| `auth/` | 身份、会话与数据权限 |
| `orders/`、`shipments/` | 订单、运单与履约操作 |
| `lines/`、`scheduling/`、`transport/` | 线路与班次、运输安排、真实执行 |
| `network/`、`regions/` | 站点服务范围与地址字典 |
| `models.py`、`migrations/` | 数据模型与迁移 |
| `tests/`、`scripts/` | 回归检查与维护脚本 |

启动和测试准备见 [README](README.md)，生产操作见 [deploy-prod.md](deploy-prod.md)，术语见 [CONTEXT.md](CONTEXT.md)，专项规格见 [文档导航](../docs/README.md)。

## 领域要求

- 业务状态、数据权限和操作资格由服务端判断；提交时重新校验，不能依赖前端按钮状态。
- 真实业务动作记录服务器时间；计划、预测与实际时间分开处理。
- 线路与班次由 `lines` 管理，运输计划与任务链由 `scheduling` 管理，执行由 `transport` 管理。
- 当前安排统一使用运输线路与班次；历史规格不代表仍支持旧 path 接口或模型。
- 修改接口或字段时检查事务、幂等、权限、历史关联以及客户端契约。

## 验证与数据保护

- 使用本目录虚拟环境；回归测试入口为 `python -m unittest discover -s tests -v`，数据库准备按 README。
- 数据库测试使用隔离测试库，执行前确认连接目标，不能对开发库或生产库运行清库测试。
- 模型变化通过新迁移表达；执行迁移或清理前确认备份与恢复方式，不改写历史业务事实。
- `.env`、`backups/` 及生产配置包含敏感或高影响内容，操作前检查范围。
